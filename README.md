# Steam Pulse

A personalized gaming dashboard that tracks your Steam playtime and recommends soundtracks using Gemini AI.

View your app in AI Studio: https://ai.studio/apps/7855f6aa-74b3-4483-a8e5-3f9fd34e9a86

## Run Locally (Android)

**Prerequisites:** Android Studio, JDK 17+

1. Open the project folder in **Android Studio**.
2. Sync the project with Gradle files.
3. Replace the placeholder API keys in `MainActivity.kt`:
   - `YOUR_STEAM_API_KEY`
   - `YOUR_GEMINI_API_KEY`
4. Build and run the app on an Android Emulator or a physical device using Android Studio.
